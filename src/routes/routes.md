# Routes

The `routes` directory contains file-based page routes for ProgressOS managed by TanStack Router.

## Files

| File | Description |
|---|---|
| `README.md` | TanStack Router file-based routing architecture and convention overview documentation. |
| `__root.tsx` | Root application layout component wrapping all routes with HTML structure and providers. |
| `achievements.tsx` | Route page displaying unlocked badges, progress milestones, and streak achievements. |
| `analytics.tsx` | Productivity analytics route showing focus charts, consistency heatmaps, and stats. |
| `dashboard.tsx` | Main dashboard route displaying real-time productivity stats, active missions, and reflection status. |
| `focus.tsx` | Dedicated focus timer and productivity session tracking route page. |
| `index.tsx` | Root entry route automatically redirecting users to `/dashboard` or `/login`. |
| `login.tsx` | User authentication sign-in route page with form validation. |
| `missions.tsx` | Mission management route page for tracking daily and weekly action goals. |
| `projects.tsx` | Projects overview route page listing active projects and development progress. |
| `reflect.tsx` | Daily reflection entry route allowing users to submit ratings and personal retrospectives. |
| `settings.tsx` | User profile settings and application preferences route page. |
| `signup.tsx` | Account registration route page for creating new user credentials. |
