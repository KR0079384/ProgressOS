# Hooks

The `hooks` directory contains custom React hooks for global authentication state, responsive screen layout detection, and daily reflection data fetching.

## Files

| File | Description |
|---|---|
| `use-mobile.tsx` | Custom hook for detecting mobile viewport breakpoint (`<768px`) using media queries. |
| `useAuth.ts` | Authentication state hook providing current user session, auth status, and auth actions. |
| `useReflections.ts` | React Query hook for fetching, creating, updating, and querying user daily reflection records. |
