# Reflection Components

The `reflection` directory contains interactive forms and card views dedicated to submitting, reviewing, and analyzing daily personal reflections.

## Files

| File | Description |
|---|---|
| `ReflectionForm.tsx` | Multi-step interactive form component for logging daily mood, focus scores, wins, and improvement notes. |
| `ReflectionInsight.tsx` | Summary card presenting AI-generated insights, trends, and retrospectives based on historical reflections. |
