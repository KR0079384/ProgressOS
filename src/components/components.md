# Components

The `components` directory contains modular React UI components used throughout ProgressOS, structured into dashboard widgets, layout containers, reflection forms, and reusable UI primitives.

## Files

*No direct child files in this directory.*

## Subdirectories

| Directory | Description | Wiki |
|---|---|---|
| `dashboard/` | Dashboard-specific metrics, widgets, charts, lists, and activity feed components. | [dashboard/dashboard.md](dashboard/dashboard.md) |
| `layout/` | Structural layout components such as top bar, sidebar navigation, app shell, and ambient glow. | [layout/layout.md](layout/layout.md) |
| `reflection/` | Interactive forms, cards, and insights for daily productivity reflections. | [reflection/reflection.md](reflection/reflection.md) |
| `ui/` | Reusable primitive UI components built with shadcn/ui, Radix UI, and Tailwind CSS. | [ui/ui.md](ui/ui.md) |
