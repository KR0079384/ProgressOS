# Layout Components

The `layout` directory contains shell and structural navigation components that define the overall visual frame and global user interface of ProgressOS.

## Files

| File | Description |
|---|---|
| `AmbientGlow.tsx` | Background visual effect rendering dynamic ambient lighting gradients behind application content. |
| `AppShell.tsx` | Root layout wrapper combining TopBar, Sidebar navigation, AmbientGlow, and page outlet content. |
| `CommandPalette.tsx` | Keyboard-driven (`Cmd+K`) command palette modal for fast navigation and actions. |
| `Sidebar.tsx` | Collapsible side navigation panel containing main section links, user profile details, and status. |
| `TopBar.tsx` | Top header bar containing breadcrumbs, global search trigger, notification icons, and user avatar. |
