# UI Primitives

The `ui` directory contains reusable primitive UI components built on top of Radix UI and styled with Tailwind CSS via shadcn/ui.

## Files

| File | Description |
|---|---|
| `PageHeader.tsx` | Standardized header component for section titles and page actions. |
| `accordion.tsx` | Collapsible accordion component for expandable content panels. |
| `alert-dialog.tsx` | Modal dialog component for critical user confirmations and alerts. |
| `alert.tsx` | Notification callout banner component for informational and warning messages. |
| `aspect-ratio.tsx` | Container component for maintaining fixed width-to-height element ratios. |
| `avatar.tsx` | User profile avatar image component with fallback initials display. |
| `badge.tsx` | Compact status badge component for labels, tags, and counts. |
| `breadcrumb.tsx` | Hierarchical navigation breadcrumb bar component. |
| `button.tsx` | Standard customizable button component supporting variants and sizes. |
| `calendar.tsx` | Date picker and interactive calendar component. |
| `card.tsx` | Flexible container card component with header, content, and footer slots. |
| `carousel.tsx` | Touch-enabled slideshow carousel component built with Embla Carousel. |
| `chart.tsx` | Wrapper and helper components for rendering Recharts visualizations. |
| `checkbox.tsx` | Form checkbox control component for boolean selections. |
| `collapsible.tsx` | Toggleable container component for showing/hiding content sections. |
| `command.tsx` | Search and command palette container primitive built on cmdk. |
| `context-menu.tsx` | Right-click popup context menu component. |
| `dialog.tsx` | Standard overlay modal window dialog component. |
| `drawer.tsx` | Slide-out bottom sheet drawer component built on Vaul. |
| `dropdown-menu.tsx` | Popover dropdown menu component triggered by user actions. |
| `form.tsx` | Form field wrappers and validation context integrated with React Hook Form. |
| `hover-card.tsx` | Popover card triggered by hover interactions for contextual previews. |

| `label.tsx` | Form field label element component associated with form controls. |
| `menubar.tsx` | Desktop application-style horizontal menubar dropdown component. |
| `navigation-menu.tsx` | Top-level website menu bar component with rich sub-navigation popups. |

| `popover.tsx` | Floating popover container component triggered by click events. |

| `sonner.tsx` | Toast notification provider and trigger component built on Sonner. |

| `table.tsx` | Data table container, row, header, and cell components. |

| `textarea.tsx` | Multi-line text input control component. |
| `toggle-group.tsx` | Group of toggle buttons supporting single or multiple selection. |
