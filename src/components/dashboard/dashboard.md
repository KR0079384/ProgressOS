# Dashboard Components

The `dashboard` directory contains React components that render data visualizers, activity widgets, progress metrics, and action items on the main ProgressOS dashboard.

## Files

| File | Description |
|---|---|
| `AchievementsRow.tsx` | UI row displaying recently unlocked user badges, milestones, and achievements. |
| `ActivityFeed.tsx` | Timeline widget displaying recent user actions, completed missions, and reflection submissions. |
| `ConsistencyHeatmap.tsx` | Heatmap chart visualizing daily activity frequency, contribution counts, and productivity streaks. |
| `FocusHoursChart.tsx` | Bar chart component visualizing focus hours logged per day across weekly/monthly timeframes. |
| `MissionList.tsx` | Active mission tracking card allowing interactive checkoffs and task progress updates. |
| `MomentumRing.tsx` | SVG circular progress ring indicating real-time productivity momentum score. |
| `ProjectsGrid.tsx` | Grid component presenting active projects, progress percentages, and status tags. |
| `ReflectionSummary.tsx` | Widget displaying key takeaways, ratings, and AI summaries from recent reflection entries. |
| `SurvivalIndicator.tsx` | Compact badge indicator tracking daily survival streak and habit compliance status. |
